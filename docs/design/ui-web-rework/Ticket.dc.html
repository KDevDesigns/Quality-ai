When a teller voids a payment and records the next one, the new Official Receipt number skips one value. OR numbers must stay gap-free per collector and series.

  1. Record a payment. The system issues OR 0048213.
  2. Void that payment.
  3. Record the next payment. The system issues OR 0048215 instead of 0048214.
